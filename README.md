## 🌟 Features

### 🏋️ Exercise Logging

- **NLP-Based Quick Logger** - Log workouts naturally: "bench press 4x8 at 80kg"
- **Manual Exercise Logger** - 100+ exercises organized by muscle groups
- **Smart Calorie Tracking** - Automatic calorie estimation
- **Detailed Metrics** - Track sets, reps, weight, duration, distance

### 📅 Calendar & Check-ins

- **Visual Calendar** - Monthly view with workout indicators
- **Streak Tracking** - Current and longest workout streaks
- **Daily Check-ins** - Mark workouts completed or missed
- **Progress Visualization** - See your consistency at a glance

### ✨ Custom Workout Plans

- **Plan Builder** - Create personalized workout programs
- **Exercise Library** - Choose from 100+ categorized exercises
- **Multiple Programs** - Save and switch between different plans
- **Pre-built Templates** - 5 professional workout programs included

### 📊 Progress Tracking

- **Workout History** - Complete log of all exercises
- **Personal Records** - Automatic PR tracking for max lifts
- **Progress Photos** - Upload and track visual progress
- **Detailed Statistics** - Weekly, monthly, and all-time stats

### 🎯 Advanced Features

- **BMI & BMR Calculations** - Health metrics tracking
- **Workout Templates** - Save favorite workout routines
- **Feeling Tracker** - Log how you felt during workouts
- **Notes System** - Add detailed notes to any workout

## 🛠️ Tech Stack

### Backend

- **FastAPI** - Modern, fast web framework
- **SQLAlchemy** - SQL ORM
- **Pydantic** - Data validation
- **JWT Authentication** - Secure user sessions
- **Custom NLP Engine** - Natural language workout parsing

### Frontend

- **Vanilla JavaScript** - No frameworks, pure performance
- **Modern CSS** - Gradients, animations, responsive design
- **Local Storage** - Client-side session management

### Database

- **SQLite** - Lightweight, serverless database
- 8 tables: Users, Workouts, Programs, Check-ins, Records, Photos, Templates, Measurements
